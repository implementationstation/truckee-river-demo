Below are **3 Nuxt 4 / Vuetify 4–style “Values Grid” components**. All are **docs-centric, simple, no images, icon-driven**, and suitable for an outdoor/rafting brand.

I’ll assume Material Design Icons (MDI) are available via Vuetify (`icon="mdi-..."`).

---

# 1) Clean Minimal Grid (best default / docs-style)

Simple, readable, very Vuetify-native.

```vue
<template>
  <v-container class="py-12">
    <v-row class="text-center mb-8">
      <v-col>
        <h2 class="text-h4 font-weight-bold">Our Values</h2>
        <p class="text-medium-emphasis">
          What defines every rafting experience we run.
        </p>
      </v-col>
    </v-row>

    <v-row>
      <v-col
        v-for="(item, i) in values"
        :key="i"
        cols="12"
        md="4"
      >
        <v-card variant="tonal" class="pa-6 h-100">
          <v-icon size="36" class="mb-4" color="primary">
            {{ item.icon }}
          </v-icon>

          <h3 class="text-h6 font-weight-bold mb-2">
            {{ item.title }}
          </h3>

          <p class="text-body-2 text-medium-emphasis">
            {{ item.text }}
          </p>
        </v-card>
      </v-col>
    </v-row>

    title: "Real Adventure",
```

# Quick Guidance (what each is best for)

* **Version 1 (Minimal Grid)** → documentation style, clean trust-building
* **Version 2 (Glass / Elevated)** → marketing homepage hero sections
* **Version 3 (Icon Compact)** → fast scanning, mobile-first UX, dense layouts
